# CDP (앱푸시·인앱 메시지)

> 외부 공유용 참고자료 · 한국관광공사 국내디지털마케팅팀 · 2026-10-02 작성 · 2026년 FGI 현황분석 참고용
> 공개 화면과 공개 가능한 운영 기준만 정리했습니다. 내부 실적 수치, 관리자(어드민) 접속 정보, 개인정보는 넣지 않았습니다.

## 개요

- 대구석은 **CDP(고객 데이터 플랫폼)**로 앱 이용자에게 **앱푸시**와 **인앱(인웹) 메시지**를 보냅니다. B2C 앱 이용자와 소통하는 핵심 채널입니다.
- 앱푸시는 주 2회 안팎으로 운영합니다. 이벤트, 캠페인, 지원사업 상품, 테마관 등을 알립니다.

## 기능

| 기능 | 내용 |
|---|---|
| 세그먼트 | 전체 사용자 / 회원 그룹을 만듭니다. 속성 조건과 행동(이벤트) 조건을 AND/OR로 조합합니다 |
| 푸시 캠페인 | 발송 대상 → 메시지 → 발송 설정 |
| 인앱 캠페인 | 세그먼트 → **트리거 조건**(이용자 행동에 반응해 노출) → 메시지(중앙 팝업·하단·상단 배너) |
| A/B 테스트 | 메시지 효과 비교 |
| 실시간 이벤트 조회 | 이용 행동 데이터 확인 |

## 운영 원칙

- 운영안 확정 → 테스트 발송 → 최종 점검 → 발송 → 결과 보고 순으로 진행합니다.
- 광고성 푸시는 (광고) 표기와 수신거부 방법을 명시합니다.
- 오발송을 막기 위해 담당자 교차 점검, 발송 중 설정 변경 금지 등의 통제 장치를 둡니다.

## 분석 포인트 (참고)

- 핫·콜드 유저의 푸시 반응 차이, 앱 재방문 유도 요인을 묻는 질문의 배경이 됩니다.
