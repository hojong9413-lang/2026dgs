# 여행기사

> 외부 공유용 참고자료 · 한국관광공사 국내디지털마케팅팀 · 2026-10-02 작성 · 2026년 FGI 현황분석 참고용
> 공개 화면과 공개 가능한 운영 기준만 정리했습니다. 내부 실적 수치, 관리자(어드민) 접속 정보, 개인정보는 넣지 않았습니다.

공사가 대구석에서 가장 힘을 싣는 콘텐츠입니다.

## 만드는 방식

- **테마 기획:** 관광지 또는 **큐레이션 테마**를 잡습니다. 큐레이션 테마는 "아쿠아리움 여행", "박물관 투어"처럼 하나의 주제로 여러 장소를 묶는 방식입니다.
- **관광지 매칭:** 기사 1건에 관광지 **3~5곳**을 매칭합니다.
- **취재·촬영:** 대내외 협업(지자체·지사·유관기관 등)으로 취재하고, 관광지마다 **사진 5컷 이상을 직접 촬영**합니다.
- **저작권:** 글과 사진의 저작권은 공사가 확보합니다. 인물 사진은 초상 이용 동의를 받습니다. 공공누리 유형을 붙여 민간에 개방합니다.
- **관광정보 연동:** 기사에 나온 관광지 정보는 관광정보 DB([[06_POI-관광정보DB]])에 등록하거나 현행화합니다.
- 취재부터 발행까지 평균 2주 안팎이 걸립니다.

## 기사 유형

| 유형 | 내용 |
|---|---|
| 신규 | 새 주제·관광지로 새로 쓰는 기사 |
| 현행화 | 이전 기사를 현재 기준으로 다시 쓰고 사진도 다시 수급 |
| 지역 협업 기사 | 지자체·기관과 협업한 코스형 기사 |
| 큐레이션 기사 | 특정 테마·기획 기반 |
| 테마형 기사 | 시기·주제형 (예: 명절에 가기 좋은 여행지) |

## 노출 위치

- GNB 여행 > 여행 정보 > 여행기사
- 대구석 '여행수집' 테마관, 가볼래-터([[03_가볼래-터]]), 메인 AI 요약

## 원고 기준 (요약)

- 제목 2줄, 전문 3~4줄, 소제목, 장소당 1~2문단 본문, 기본정보, TIP, 태그 10개
- 사진은 기사당 15~20장 수준이며, 대체텍스트를 입력합니다.
- 출처 표기와 공공누리 유형을 표시합니다.
