# 배지랜드

> 외부 공유용 참고자료 · 한국관광공사 국내디지털마케팅팀 · 2026-10-02 작성 · 2026년 FGI 현황분석 참고용
> 공개 화면과 공개 가능한 운영 기준만 정리했습니다. 내부 실적 수치, 관리자(어드민) 접속 정보, 개인정보는 넣지 않았습니다.

## 개요

- 대구석 이용 활동(열람, 참여, 여행 인증 등)에 따라 **배지**를 주고 **랭킹**을 매기는 활동 보상 서비스입니다.
- 사용자 화면: **메인 / 나의 배지도감 / 랭킹왕국**

## 배지

| 구분 | 성격 |
|---|---|
| 일회성 | 기간과 상관없이 1회만 발급 |
| 난이도형 | 단계·점수가 있는 배지 |
| 이벤트 | 기간 한정 운영 (예: 이벤트 배지, 도전! 열람왕) |
| 기타 | 배지도감에만 노출 |

- 배지 그룹: 참여 / 모험 / 이벤트 / 여행
- 배지마다 도전과제와 설명이 있고, 과제 수행 화면으로 바로 연결하는 링크를 둘 수 있습니다.
- 새로운 유형의 과제를 만들려면 개발(API 연동)이 필요합니다.

## 랭킹

- 현재 랭킹(실시간 누적), 월간 랭킹, 연간 랭킹
- 월간·연간 랭킹전 혜택(경품)을 운영합니다.

## 분석 포인트 (참고)

- 배지·랭킹이 핫 유저의 지속 이용 동기가 되는지, 콜드 유저에게는 어떻게 인식되는지 확인하기 좋습니다.
