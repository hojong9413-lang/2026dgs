# 가볼래-터

> 외부 공유용 참고자료 · 한국관광공사 국내디지털마케팅팀 · 2026-10-02 작성 · 2026년 FGI 현황분석 참고용
> 공개 화면과 공개 가능한 운영 기준만 정리했습니다. 내부 실적 수치, 관리자(어드민) 접속 정보, 개인정보는 넣지 않았습니다.

대구석의 **구독형 국내여행 정보 서비스**입니다. 매월 1일(주말·공휴일이면 다음 날) '제철 여행' 콘셉트로 발행합니다.

## 제공 내용

- 매월 갈 만한 곳 **큐레이션** (메인 테마 1개 + 서브테마 3개)
- 여행정보, **약식 여행기사**(가볼래-터 페이지 전용 기사, 1,500자 안팎), 월별 여행지도
- 구독자 참여형 **미션**: O/X 퀴즈, 빈칸 채우기, 댓글달기 중 매월 1개
- **여행복권** 경품 이벤트
- 발송 채널: 카카오 알림톡·캐러셀 메시지 (월 최대 2회: 발행 알림 + 참여 독려). 메일 서비스는 2026년 8월에 종료했습니다.

## 월간 운영 흐름 (예: 2026년 8월호)

| 단계      | 기간                   |
| ------- | -------------------- |
| 발행      | 1일 무렵 (8월호는 8.3.)    |
| 미션 참여   | 발행일 ~ 15일 무렵         |
| 여행복권 뽑기 | 16일 ~ 25일 무렵 (약 10일) |
| 경품 지급   | 복권 종료 후              |

- 날짜는 월호마다 조금씩 다릅니다.
- 지자체·지사와 협업한 기사를 월 1건 정도 넣고, 협업 기관의 지원 물품을 복권 경품으로 쓰기도 합니다.

## 분석 포인트 (참고)

- 미션 → 복권으로 이어지는 **반복 참여 구조**가 핵심 리텐션 장치입니다. 핫 유저 정의에 참고할 수 있습니다.
