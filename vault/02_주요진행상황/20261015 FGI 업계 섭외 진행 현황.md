## 3. 그룹별 세부 진행 및 조치 사항
### 가. G5 그룹 (플랫폼 및 여행사 / 목표 5명) : 
- 플랫폼 3개사 : 여담, 바바그라운드(불참) / 맘맘(메일발송, 유선연락정보 없음)
- 여행사 3개사 : 승우여행사(조건부 참석) / 해밀여행사(회신대기중) / 홍익여행사 (공사 선접촉 결과 확인 공유 예정)

### 나. G6 그룹 (지자체 및 공공기관 / 목표 5명) : 
- 지자체 5개기관 : 칠곡군(참석), 포천시(조건부 참석), 통영시, 서초구(불참), 영주시(회신대기중)
- 공공기관 5개기관 : 대구문화예술진흥원(참석) / 충북문화재단, 국립수목원, 한국수목원정원관리원 (불참) / 도로교통공사(공사 선접촉 결과 확인 공유 예정)

### 다. G7 그룹 (민간기업 및 제휴사 / 목표 4명) : 
- 민간 : STI(참석) / 캐논(회신대기중) / 에버랜드(불참) / H.Point(메일발송 확인안됨)
